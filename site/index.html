diffviz
Demo GitHub

See what your coding agent changed.

diffviz graphs every file a coding agent changes in your TypeScript project, live from git, and labels the graph with the agent's own description of the work.

Open the demo View on GitHub

Nothing to install for the demo. To use it on your own project: npx diffviz

How it works

1

The graph comes from git

Every file changed since the last commit becomes a node. ts-morph reads its imports, and each import becomes an arrow from the importing file to the file it imports. Imported files that didn't change are shown grayed out, one hop away.

2

The agent adds the labels

After every response, Claude Code writes a short description of its work: a summary, a note per file, layers that group related files, and a label per import. diffviz validates it and drops anything that doesn't match the real graph.

3

A commit closes the chapter

The work between two commits is a session part. When you commit, diffviz saves its final graph, every version of the agent's description and your prompts, then starts again from an empty graph.

The AI never draws the graph

Nodes and arrows are built deterministically from git and the TypeScript compiler, so the picture is always accurate. The agent can only describe what is there: a description of a file that doesn't exist, or an arrow that isn't a real import, is discarded. If the agent's output is missing or invalid, the graph still renders and the status bar says what went wrong.

Try it on your project

  1. In the root of a TypeScript project that uses git, run npx diffviz. It opens in your browser.
  2. Commit the CLAUDE.md instructions it adds, then start Claude Code in the same folder.
  3. Work as usual. The graph updates as files change, and the labels after each response.
  4. Commit when a part of the work is done, and the next part starts fresh.

Needs Node.js 22.22 or newer and git. Everything runs on your machine.
